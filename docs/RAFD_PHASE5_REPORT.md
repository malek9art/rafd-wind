# RAFD Desktop — تقرير المرحلة 5

## الحالة

- **المرحلة:** 5 — استكمال الواجهات التجارية والطباعة والتقارير والتصدير
- **الحالة:** مكتملة محليًا
- **النطاق المنفذ:** إدارة التشغيل، التصدير، إعدادات الطابعة، طباعة HTML، تحسين CSV والتقارير

## التغييرات الأساسية

### شاشة الإدارة

تمت إضافة `AdminScreen` وتبويبات:

- إعدادات المتجر.
- المستخدمون للمدير.
- المصروفات.
- الحسابات البنكية.
- الطرفيات.
- سجل التدقيق.

وتستخدم الشاشة قنوات IPC الموجودة مع إبقاء الصلاحيات محمية في العملية الرئيسية.

### إعدادات الطابعة

تمت إضافة migration v7 لإعداد:

- منفذ الطابعة مثل `COM3`.
- سرعة الاتصال.
- عرض الإيصال 58 أو 80 ملم.

لم تعد الطباعة الحرارية تختار أول منفذ عشوائيًا؛ يجب تحديد المنفذ من إعدادات المتجر.

### طباعة HTML

تم إصلاح مسار `printer:print-html` بحيث:

- ينشئ نافذة طباعة مخفية.
- يحمل HTML المرسل فعليًا.
- يطبع المستند المطلوب بدل الصفحة الحالية.
- يعيد فشلًا حقيقيًا عند عدم تجهيز المستند.
- يغلق نافذة الطباعة بعد الانتهاء.

### الطباعة الحرارية

- عدم وجود `serialport` يعيد فشلًا حقيقيًا بدل نجاح وهمي.
- عدم إعداد منفذ الطابعة يعيد فشلًا واضحًا.
- عدم توفر المنفذ المحدد يعيد فشلًا واضحًا.
- تمت إضافة مستمع لأخطاء المنفذ.

### CSV والتقارير

- تهريب عناوين CSV والصفوف بشكل موحد.
- دعم الفواصل والاقتباسات والأسطر الجديدة و``.
- الإبقاء على UTF-8 BOM لدعم Excel العربي.
- استخدام التاريخ المحلي بدل تحويل منتصف الليل إلى UTC.
- إضافة طريقة الدفع وحالة الفاتورة إلى تصدير المبيعات.
- تصحيح وصف المبيعات النقدية.
- استكمال تصفية التقارير للشراء المستلم فعليًا.
