# RAFD Desktop — تقرير المرحلة 6

## الحالة

- **المرحلة:** 6 — النسخ الاحتياطي والاستعادة والتحديثات
- **الحالة الحالية:** دفعة النسخ المحلي والاستعادة مكتملة محليًا
- **النطاق المنفذ:** نسخ SQLite متسقة، checksum، integrity check، استعادة مع نسخة أمان، واجهة إدارة النسخ

## التغييرات الأساسية

### مدير النسخ الاحتياطية

تمت إضافة `src/main/backups.ts` ويقوم بـ:

- إنشاء النسخة عبر `better-sqlite3.backup()` المتوافق مع WAL.
- حفظ ملف قاعدة مستقل داخل مجلد `userData/backups`.
- إنشاء metadata بجانب كل نسخة.
- حفظ:
  - وقت الإنشاء.
  - إصدار التطبيق.
  - إصدار المخطط.
  - حجم الملف.
  - SHA256.
- التحقق من checksum.
- تنفيذ SQLite `integrity_check`.
- رفض النسخ ذات المخطط الأحدث من التطبيق.
- حذف نسخة محددة بمعرف آمن دون قبول مسار عشوائي.

### الاستعادة

الاستعادة تقوم بـ:

1. التحقق من النسخة.
2. إنشاء نسخة أمان من الحالة الحالية.
3. إغلاق قاعدة البيانات.
4. استبدال ملف SQLite.
5. حذف ملفات WAL/SHM القديمة.
6. إعادة تشغيل التطبيق لإعادة بناء المقبض والـIPC.

### الواجهة

أضيف تبويب النسخ الاحتياطية داخل شاشة الإدارة، ويتيح:

- إنشاء نسخة.
- عرض الحجم والإصدار وSHA256.
- فحص النسخة.
- الاستعادة للـAdmin.
- الحذف للـAdmin.

الـManager يستطيع إنشاء وفحص النسخ، بينما الاستعادة والحذف للـAdmin فقط.

## الاختبارات

تمت إضافة اختبارات لـ:

- إنشاء النسخة وmetadata وchecksum.
- SQLite integrity check.
- استعادة نسخة قديمة مع الاحتفاظ بنسخة أمان.
- حذف النسخ.
- حماية معرفات النسخ.
