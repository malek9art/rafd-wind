# RAFD Desktop — تقرير المرحلة 4

## الحالة

- **المرحلة:** 4 — الأمن وتسجيل الدخول والصلاحيات
- **الحالة:** مكتملة محليًا
- **النطاق:** المستخدمون، PIN، الجلسة، الصلاحيات، تهيئة المدير، Single Instance، إغلاق قاعدة البيانات، واجهة الترخيص

## التغييرات الأساسية

### المستخدمون والجلسة

- إضافة عداد للمستخدمين.
- إضافة مسار تهيئة أول مدير فقط عند عدم وجود مستخدمين.
- إجبار المستخدم الأول على دور `admin` وPIN صالح.
- تسجيل المدير الجديد مباشرة في الجلسة.
- منع حذف المستخدم النشط.
- تحديث الجلسة عند تعديل المستخدم النشط.
- إنهاء الجلسة عند تعطيل المستخدم النشط.

### الأدوار

تم تنفيذ الصلاحيات التالية:

| الدور | النطاق |
|---|---|
| `admin` | كل قنوات الكتابة التشغيلية وإدارة المستخدمين والإعدادات |
| `manager` | المبيعات والمشتريات والمخزون والعملاء والموردون والمصروفات والحسابات |
| `cashier` | إنشاء المبيعات والعملاء وقيود العملاء |
| `viewer` | لا يملك أي قناة كتابة |

كل قناة كتابة تمر الآن عبر:

1. التحقق من مصدر renderer الموثوق.
2. بوابة الترخيص.
3. فحص المستخدم النشط.
4. فحص صلاحية الدور.

كما أن قنوات القراءة الخاصة ببيانات المتجر تتطلب جلسة نشطة، مع إبقاء قنوات الترخيص وتسجيل الدخول وتهيئة المدير عامة بالقدر اللازم.

الاستثناء الوحيد هو تهيئة أول مدير عندما يكون عدد المستخدمين صفرًا.

### واجهة الدخول

تمت إضافة:

- `LoginScreen`.
- `SetupAdminScreen`.
- تسجيل الخروج من الشريط الرئيسي.
- عرض اسم المستخدم ودوره.
- إعادة التطبيق إلى شاشة الدخول عند تسجيل الخروج.

### الترخيص

تمت إضافة عرض مباشر لحالة الترخيص:

- انتهاء الترخيص: القراءة متاحة والكتابة متوقفة.
- قرب انتهاء الترخيص: تحذير بعدد الأيام المتبقية.

### دورة حياة التطبيق

- إضافة Single Instance Lock.
- التركيز على النافذة الحالية عند محاولة فتح نسخة ثانية.
- إغلاق قاعدة SQLite عند `before-quit`.
- إغلاق القاعدة قبل إنهاء وضع Smoke.
- معالجة أخطاء بدء التشغيل وmigration بدل ترك التطبيق في حالة غير واضحة.

## ملاحظات متبقية

- مصفوفة الصلاحيات مطبقة في IPC، لكن واجهات إدارة المستخدمين الكاملة لم تُضف بعد.
- التحقق runtime للـpayloads ما زال يعتمد جزئيًا على حراسات repositories، وسيتم توسيعه في مرحلة hardening التالية.
- الطباعة والنسخ الاحتياطي وZATCA خارج نطاق هذه المرحلة.
