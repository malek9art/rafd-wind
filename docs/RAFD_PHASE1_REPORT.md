# RAFD Desktop — تقرير المرحلة 1

## الحالة

- **المرحلة:** 1 — تثبيت الاختبارات والبنية الأساسية
- **الحالة:** مكتملة
- **النطاق:** إصلاح حتمية اختبار التقارير وإغلاق خط الأساس فقط
- **لم يتم تعديل منطق الإنتاج في هذه المرحلة**

## التغيير المنفذ

تم تعديل `tests/reports.test.ts` فقط من ناحية الاختبار:

- استخدام Vitest fake timers.
- تثبيت الساعة على `2026-07-15T12:00:00.000Z`.
- إعادة الساعة الحقيقية بعد كل اختبار عبر `vi.useRealTimers()`.

الهدف هو منع اعتماد الاختبار على تاريخ تشغيل الجهاز، وضمان وقوع البيانات التجريبية داخل نطاق التقرير المحدد.

## ملاحظات البيئة

- تم تثبيت الاعتماديات في بيئة الوكيل باستخدام `npm ci --ignore-scripts` لأن إعادة بناء الوحدة الأصلية `better-sqlite3` محليًا على Linux تعتمد على توفر ترويسات Node والشبكة.
- تغليف Windows لا يزال يجب التحقق منه على `windows-latest` حسب سياسة المشروع.
- توجد ثغرات High في اعتماديات تطوير غير مباشرة، وليست في اعتماديات الإنتاج؛ ستُعالج أو تُوثق ضمن مرحلة تأمين التغليف.
